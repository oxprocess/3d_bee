# derbeebee 3D 形态：生长、交互与数据接口

> 本文与 `dist/index.html`（形态走查）是同一份梳理：页面负责演示，这里负责把规则写清楚，方便设计、前端和算法对齐。页面中的事情、次数和日期均为演示。

## 1. 一句话

两条线同时在走：**事情线**是它为你做了什么（App 的对话、预测、准备、成长），**形态线**是它因此学会了什么（晶体与倒影）。
内核只有一个循环：观察 → 预测 → 行动 → 用结果更新预测方法。形态是这个循环在身体上留下的痕迹：**每做一件事，形态留下一处痕迹；每一处痕迹，都能在账本里找到那一行。**

## 2. 场景里有什么

| 元素 | 是什么 | 对应的学习概念 |
|---|---|---|
| 晶体（本体） | 现在替你准备下一步的方法。检验期间不动 | 当前采用的预测方法 |
| 倒影（影子） | 和本体判断同一件事、正在练习的新方法 | 并行学习的候选方法（生成并检验） |
| 水面 | 平静如镜；只有结果落下才起涟漪 | 经验流 |
| 水滴 | 一个封存的预判，悬在晶体与倒影之间 | 一般价值函数：问题、期限、答案 |
| 涟漪 | 一个真实的结果；大小是意外程度 | 时序差分误差 |
| 光柱 | 迭代时刻，倒影升上来 | 方法替换 |
| 年轮（层） | 一圈是一代，一代是一个留下来的方法 | 方法的历史 |
| 细纹 | 一圈里的一条线，是一次合格比较 | 单次经验 |

## 3. 生长过程：一个阶段一个阶段

| 阶段 | 事情线 | 形态线（本体 / 倒影 / 水面） | 用户能做什么 | 驱动它的数据 | 纪律 |
|---|---|---|---|---|---|
| 1 诞生 | 还没有事 | 小而正圆；倒影一模一样、清楚 | 转动、按住、长按（数到 1） | `generations=[核]`、`shadow=null` | 没有经历就没有方向，所以是正圆 |
| 2 对话 | 18:12 “刚下班，有点累” | 身体里的颜色流得快一阵，再静下来：它在听 | 同上 | `observe` | 流动不改变结构 |
| 3 预测 | 写下“22 点前爸妈会来确认住宿” | 一滴水凝在晶体和倒影之间；本体的颜色浓一下（64%），影子浓一下（72%） | 点水滴看预判卡 | `seal`：`pBody`、`pShadow`、`deadline`、`category` | 数字旁永远写“演示估计，不是准确率” |
| 4 准备 | 天气、酒店、药盒、家里安排 | 水面平静；水滴随期限慢慢下沉 | 同上 | `deadline − now` | 时间只让水滴下沉，不让晶体生长 |
| 5 结果 | 20:10 爸妈真的来问 | 水滴落在倒影上；涟漪大小 = 意外；倒影晃一下，颜色被搅动一阵，变一点；晶体不动 | 点水面看倒影练到哪 | `resolve`：`|结果 − p影子|` | 一次结果只做更新，不做取舍 |
| 6 迭代时刻 | 满 30 次合格比较且影子更准 | 水下亮起；它转过来，把要长新一层的那一面对着你；一道新类别颜色的光升起，晶体长出新的一层，那一类的颜色从那一侧铺开；上一代退到里面成为年轮；倒影重新一模一样 | 看 | `iterate` → `inherit` | 被继承或淘汰的是方法，身份不变 |
| 6′ 没通过 | 还不够 | 倒影往水里沉一下，继续练；晶体不变 | 看 | `iterate` → `continue` | 影子也会输，要让用户看见 |
| 7 长成 | 很多代之后 | 形状显现：宽展、收束、偏展、转向 | 挖掘、换颗对比 | 全部 `generations` | 形状只来自规则，不是另画的 |

旧稿里“完整 → 展开 → 舒展 → 新形态”四个状态，在这一版里分别是：完整的晶体 → 预判封存时两者的颜色各自变浓 → 倒影练习、清晰度变化 → 继承后多一层。

## 4. 一层一层，挖到最深

可以直接在 3D 里展开，但展开的顺序要和数据的粒度一一对应：

1. **形**：整颗晶体。身份，以及生活铺在哪几个方向。
2. **层**：剖开后的一圈。一代，一个留下来的方法。
3. **纹**：一圈里的一条细线。一次合格比较：那一天、那件事、两个概率、谁更近。

深度（`stage.setDepth(d)`）一共 N+1 个停靠点，N 是代数：

| d | 名称 | 画面 |
|---|---|---|
| 0 | 外形 | 完整的晶体与倒影 |
| 1 | 剖面 | 开蚌：上半绕离镜头最远的一侧向后翻开 108°；下半露出赤道剖面；四个方向标出现；倒影淡到 15% |
| 2…N | 第 N−d+1 代 | 剥层：最外一层从剖面那道边开始化开（带一圈亮边），剖面上留一道虚线标出它后来长到的位置 |

- **深度就是时间**：剥掉 k 层，看到的就是 k 代以前的它；时间轴上点一个日期，等价于挖到那一代。
- **聚焦**：点剖面上的一圈 → 镜头推近那一代，其余变暗；再点 → 选中一条细纹（卡片上同步高亮）。
- 选了“开蚌 + 剥层”，没选这些：爆炸图（层多就互相遮挡，看不出方向）、楔形切口（只露出一两个方向）、镜头钻进去（容易迷路，回答不了“几代”）、X 光透视（颜色叠在一起，失去光谱在身体里的通透）。

## 5. 交互语法

| 手势 | 外形时 | 剖开时 |
|---|---|---|
| 拖动 | 自由转动；松手带惯性；随后像不倒翁一样扶正 | 左右 = 转动，上下 = 俯仰视角 |
| 双指张开 / 捏合、Ctrl + 滚轮（触控板捏合） | 挖深一层 / 退回一层 | 同左 |
| 轻点 | 晶体 → “此刻的它”；水面 → 倒影；水滴 → 预判 | 一圈 → 那一代；同一圈再点 → 那一条细纹 |
| 长按 | 数一数：按代数亮 N 次，手机轻震 N 下 | 从核开始一圈圈点亮 |
| 双击 | 复位 | 复位 |
| 键盘（舞台获得焦点） | ←→↑↓ 转动 · + − 挖深/退回 · Enter 下一层 · C 数一数 · Esc 返回 · Home 复位 | 同左 |

**触摸永远不产生涟漪**：点水面只泛起一点水光（不向外扩散）。涟漪只留给真实的结果，触摸不能伪造结果。

## 6. 让人感觉到它是活的

活的感觉来自三件事：它有重量、它注意到你、它按自己的节奏在。三件事都不碰学习数据。

| 细节 | 做法 | 参数 |
|---|---|---|
| 重量 | 拖动跟手；松手后按角速度滑行，自转衰减 1.15/s；倾斜像不倒翁一样扶正（弹性 9，衰减 3.4/s） | `motion.js · Orientation` |
| 姿态 | 静止时重的一侧微微低一点，倾角来自外形的质心，最多 5.7° | `growth.restPose` |
| 注视 | 指针靠近时微微转向，最多约 5° | `stage.hover` |
| 呼吸 | 约 5.6 秒一次，缩放 ±0.45%，上下 ±0.012；闲置 25 秒后变慢、变暗；你回来它醒 | `stage.update` |
| 颜色的流动 | 色带缓慢摆动（±0.26 rad）、色相轻轻起伏（±10°），哪一类在哪一侧不变；闲置时流速降到 40% | `spec.*.phase` |
| 余温 | 按住的点泛暖色，跟着晶体转，松手后约 1 秒退去 | `uWarmPos`、`uWarmAmt` |
| 倒影慢半拍 | 倒影朝向跟随本体，速率 = 2.2 + 11 × 同步度 | `shadow.agreement` |
| 触觉 | 过一层 10ms；选中 12ms；落水 14ms；继承 24ms（仅支持的设备） | `stage.haptic` |
| 声音（建议，未实现） | 默认静音；只有两种：落水一声轻响（意外越大音越低）、继承一声玻璃音 | — |
| 减少动态效果 | 关闭呼吸、注视、惯性；动画时长 × 0.25；涟漪减弱 | `prefers-reduced-motion` |

高级感的原则：颜色全部来自同一套光谱色调，每一种都有来处，没有光晕，光都在轮廓以内：刻面的明暗、轮廓内侧的倒角、细的棱线（11.6），品牌渐变只用在一个标题上；惯性、涟漪按真实物理做，只是更慢更轻；**动作的分量跟事情的分量一致**：呼吸和颜色的流动一直在、颜色浓一阵偶尔出现、涟漪一件事一次、光柱一代一次。

## 7. 生长规则（公式）

方向 ω 为单位向量，y 朝上。类别 c 围在水平一圈，方向 `d_c = (cos φ_c, 0, sin φ_c)`（演示：工作 0°、健康 90°、朋友 180°、家人 270°，按色相顺序排，相邻两类颜色也相邻；账本里没写方位角时自动按色相排）。

- 核（第 1 代）：`R₁(ω) = r₀ = 0.5`
- 第 k 代的厚度：`T_k(ω) = t_k · [1 + a_k · (K_k(ω) − K̄)]`
  - 定向核：`K_k(ω) = Σ_c w_{k,c} · ((1 + ω·d_c)/2)^P · (1 − ω_y²)^Q`，`P = 1.6`，`Q = 2`；`K̄` 是 K 在球面上的平均值，所以“鼓多少”只挪动厚度，不凭空变厚
  - **长多厚**：`t_k = 0.17 · √(n_k / 30) · (0.5 + 0.5 · novelty_k)`
  - **鼓多少**：`a_k = 0.08 + 1.17 · novelty_k`（新事朝那一侧鼓；同一件事再练，几乎均匀地包一圈）
  - **长在哪里**：`w_{k,c}` = 这一代的比较来自各类别的比例
- 外边界：`R_k(ω) = R_{k−1}(ω) + T_k(ω)`；法线解析求出：`n ∝ R·ω − ∇ₛR`（无接缝、无极点问题）
- **外形是晶体**（`core/growth.js · diamondField`）：赤道上一类事一个角，第 k 代朝类别 c 的角伸出 `e_k(c) = R_k(d_c)`；上下两个尖的高度 = 赤道各角的平均值 × `DIAMOND = { top: 1.22, bottom: 1.6 }`：轮廓照那颗绿色的宝石，修长，上尖短、下尖长；哪一类事长得多，那个角就伸得远。每一代是一个完整的凸多面体（2n 个平的三角面），一个套一个；剖面是一圈套一圈的多边形环带
- **什么颜色**：层色 = 类别色按“此前同类代数 × 0.07”加深（颜色“少而深”的来由）。显示时先落进当前色彩方向的色调（`core/tone.js`），再加深；表面颜色见第 11 节
- **什么时候长**：只有 `inherit` 追加一层

实测（演示数据）：宽展 赤道/极点 1.42；收束 1.12，9 圈；偏展 朝工作一侧 1.49；转向 里 4 圈 1.13、整体 1.35。

## 8. 数据接口

### 8.1 账本（只追加）

```jsonc
{
  "policy": { "minComparisons": 30 },
  "categories": [{ "id": "family", "label": "家人", "color": "#EFC3CF", "azimuth": 270 }],
  "generations": [
    { "gen": 1, "bornAt": "2026-01-06T09:00" },                      // 核
    { "gen": 2, "bornAt": "…", "category": "family", "source": "爸妈出游的准备",
      "learned": "出发前两天，先把酒店和药准备好。", "comparisons": 34, "wins": 21,
      "novelty": 0.9, "mix": { "family": 1 }, "retiredAt": "…",
      "lamellae": [{ "at": "…", "category": "family", "outcome": true, "pBody": 0.64, "pShadow": 0.72, "note": "爸妈问起酒店" }] }
  ],
  "shadow": { "startedAt": "…", "category": "friends", "source": "周末的约饭", "learned": "…", "novelty": 0.8, "lamellae": [] },
  "predictions": [{ "id": "p-hotel", "question": "…", "category": "family", "sealedAt": "…", "deadline": "…",
                    "pBody": 0.64, "pShadow": 0.72, "status": "sealed", "prepared": ["…"] }],
  "events": [{ "seq": 1, "type": "observe", "at": "…", "text": "…" }]
}
```

事件：`observe`（对话）· `seal`（预测）· `prepare`（准备）· `resolve`（结果，影子追加一条细纹）· `iterate`（迭代时刻：满足条件则 `inherit`，否则 `continue`）· `practice`（给影子一个新候选）。
继承条件：`n ≥ minComparisons` 且影子胜率 > 0.5（一次比较里，离结果更近的一方胜）。

### 8.2 每个细节 ← 哪个字段

| 元素 | 视觉细节 | 字段 | 何时变 |
|---|---|---|---|
| 晶体外形 | 四个角各伸多远 | `generations[].mix · comparisons · novelty` | 继承 |
| 层 | 层数 = 代数 | `generations.length` | 继承 |
| 最外一层 | 颜色、厚度 | `generations[-1].category · comparisons` | 继承 |
| 细纹 | 一条 = 一次比较；意外越大越深 | `generations[k].lamellae[]` | 继承时冻结 |
| 静止姿态 | 重的一侧低一点 | 外形质心 | 继承 |
| 倒影 | 比晶体多出的那一层 | `shadow.lamellae.length / minComparisons` | 每次结果 |
| 倒影清晰度 | 水下模糊程度 | `0.18 + 0.82 · 进度^0.65 · clamp((胜率 − 0.3)/0.4)` | 每次结果 |
| 倒影跟随 | 慢半拍 | 最近 8 次 `|p本体 − p影子|` | 每次结果 |
| 水滴 | 悬着 = 已封存；越低越接近期限 | `predictions[sealed].deadline` 与 `now` | 封存 / 时间 |
| 颜色 | 每类事的颜色在它长出来的一侧；长得越多那一片越宽；代数越多越浓 | `categories[].azimuth` · 各代 `t × lobes[].w` 按类别求和 · `generations.length` | 继承 |
| 浓淡 | 封存时本体与倒影的颜色各浓一下 | `pBody`、`pShadow` | 封存 |
| 涟漪 | 振幅 = `0.55 + 1.7 · |结果 − p影子|`；颜色 = 类别 | `resolve` | 结果到来 |
| 方向标 | 四类事的方位 | `categories[].azimuth` | 配置 |
| 呼吸与流动 | 在场，不是数据 | 会话在场 | 一直 |

同一张表在代码里是 `core/view.js` 的 `BINDINGS`，“接口透视”直接读它。

## 10. 需要统一的口径

1. 本体 64%、影子 72%，全篇统一（结果发生了，影子更近，与后面的继承一致）。
2. 继承门槛只有一个：满 30 次合格比较，且影子更准。图 10 的“24 次”、剖面页里 22 次就留下来的层，都要改。
3. 核就是第 1 代；“数一数”从核开始数。
4. “突变”改为“新形态”。
5. 去掉“全新外在自我”“更高级”：身份不变，变的是方法和结构。
6. “外在自我”处写全：它属于你，放大你；它不是你。
7. 先 18:12 准备好，再 20:10 爸妈来问。
8. 继承或淘汰的主语是方法：“触发迭代时刻，决定哪一种方法留下。”
9. 点水面不起涟漪；演示里的“落下一件事”按钮要写明“模拟”。
10. 收束的颜色来自工作与家人，“少而深”是同类事一代代加深，不是另选的蓝紫色。
11. 练习状态不只靠颜色：倒影偏向它在练的那类事，但会和那类事本身的颜色混在一起，所以还要靠虚线（缩略图）、模糊（倒影清晰度）和“练习中 n/30”区分。
12. 形态没由真实学习记录驱动之前，页面标“示意”。

## 11. 色彩：Apple Intelligence 式（已选定）

光谱在它身体里，没有光晕。先把参考图（中性浅灰底上一团柔和的光谱）拆开：

1. **颜色在身体里。**光谱就是物体自己的颜色，边缘干净；身后那圈辉光不要。
2. **几块色区，宽而柔的交界。**绿、琥珀、玫红、兰紫、蓝各占一片，交界宽而柔，不是一张彩虹贴图。落到晶体上，交界处保持彩度：相近的颜色按色相过渡，相对的颜色往兰紫那边绕，不走灰。
3. **亮来自光。**参考图里是一团光；落到晶体上，五彩极光就在表面上，朝光的面亮而透，高光滑过刻面（11.6）。
4. **每一种都鲜亮。**参考图里琥珀、玫红最饱满；落到晶体上，绿和蓝也按 Apple 的系统色拉到同样鲜亮（第二轮反馈：颜色要更鲜艳、五种颜色都要在）。
5. **中性浅灰底** `#F2F1F6`（深色 `#0E0E13`）。页面令牌一起换成中性色。

### 11.1 每一种颜色的来处

| 看到的 | 来自 | 参数 |
|---|---|---|
| 一片颜色在哪一侧 | 类别方位角 `φ_c`（就是那一类事的角），按色相顺序排 | `categories[].azimuth` |
| 这一片多宽、多占上风 | 分量 `s_c = Σ_k t_k · w_{k,c}`，除以最大值归一 | 宽 `0.95 + 0.6·s`，强度 `0.45 + 0.85·s` |
| 多浓 | 成熟度 `m = clamp((N − 1) / 4)`，N = 代数 | 彩度 × `(0.4 + 0.6·m)`，亮度朝 0.93 退 |
| 挖进去变淡 | 剥到第 k 代，只算前 k 代 | 同上 |
| 倒影的颜色 | 本体 + 候选层 × 练习进度 | `shadow.progress` |
| 上尖薄荷、下尖兰紫 | 固定的框，不是数据 | `#6EE7D0` / `#B36BE0`，纬度约 45° 以上 |
| 缓慢流动 | 在场，不是数据 | 见第 6 节 |
| 剖面的环带 | 同一套色调，提亮 22%（大片平面比刻面显得重） | `writeCapData` |

一次都没长过的类别也在，只留一道窄而淡的影子：“生活的这一面还空着”。

### 11.2 颜色场怎么算

对晶体自己坐标里的方向 ω（颜色挂在晶体身上，跟着它转）：

- 取色用方位 φ 和高度 y（−1 下尖，0 赤道，1 上尖；按这个面自己的尖来量，平的面上同一高度是一条直线）。每个面以它中间一段方位为主：`φ = φ面 + 0.5·(φ − φ面)`，一个面是一段简洁的线性渐变，面与面各有主色。
- 每类权重 `k_c = [exp(−Δφ² / width²) · (0.45 + 0.85·s_c) · (1 − 0.6·y²)]²`；两极 `k = [1.05 · smoothstep(0.15, 0.95, ±y)]²`。平方再归一：每一片中间较纯，交界宽而柔。
- 在 **OKLab** 里混，分两步。先混赤道一圈：亮度与彩度按权重平均；色相一致度（单位色相向量的平均长度）在 0.35–0.8 之间逐渐改为按色相平均，彩度不掉；几乎相对的两种颜色往兰紫那边绕，不走灰。再往两个尖过渡：份额只看高度（`smoothstep(0.25, 0.95, ±y)`，交界是平直的横线），在色相环上走一条定好的路、彩度不掉——上尖薄荷：金黄走绿，珊瑚、玫红走紫与蓝（切点在琥珀那个角）；下尖兰紫：暖色走粉，冷色走蓝紫（切点在绿那个角）。每个面只取中间一段方位，角上的色相不出现在面上，切点落在面与面之间，面上没有接缝。
- 琥珀和绿之间的黄绿（色相 122° 附近）往金黄挪 16°、彩度 −10%；黄的地方少压暗（深色背景的加深 −80%、背光的暗化 −50%）：压暗的黄就是橄榄色。
- 没有噪声：抛光的面上，渐变是干净的；流动是色带整体轻轻摆动。
- 彩度：`0.3 · tanh(1.45 · C / 0.3)`；超出屏幕色域的颜色往同样亮度的灰收（按通道算出收多少），不截断某一个通道，不偏色。
- 刻面、光、高光见 11.6；不走 PBR、不做色调映射（`toneMapped = false`），画出来的就是设计的颜色。倒影在着色器里按镜像取光。
- 每类事的颜色先落进同一套色调（`core/color.js · appleTone`：按色相插值饱和度与亮度，色相从参考图取样，彩度按 Apple 的系统色拉满），同类事每多练一代加深 0.07，照旧。卡片、时间轴、缩略图都经过 `core/tone.js`，和晶体对得上。

### 11.3 事件：流动与浓淡，不发光

| 事件 | 本体 | 倒影 |
|---|---|---|
| 倾听 `observe` | 流速 +5，约 3 秒回落 | 跟随本体 |
| 封存 `seal` | 浓 +0.7 × p本体；流速 +1.5 | 浓 +0.7 × p影子；流速 +1.5 |
| 结果 `resolve` | 不动 | 流速 +3 + 7 × 意外；浓 +0.3 + 0.8 × 意外；之后按同步度（0.25 + 1.1 × 同步度）回到和本体一致 |
| 继承 `inherit` | 用 2.2 秒转过来，把新长的一面对着你；新的分量以 1.4/s 铺开；浓 +1.0；流速 +3；光柱是新类别的颜色 | 重新和本体一样 |

浓（boost）让彩度 × `(1 + 0.3·boost)`，每秒衰减约 0.7；待揭晓期间按概率保持一点浓度。

### 11.4 为什么不要光晕

1. 光晕不属于任何数据。晶体身上每一种颜色都能在账本里找到来处，光晕找不到。
2. 一直亮着，像一直在听：那是 Siri 的签名，也和“它不是你”的分寸不合。
3. 浅色底上，光晕会把轮廓洗软；而轮廓本身是数据（哪个角伸多远）。

### 11.5 另外两个方向（留作对比）

`stage.setLook(id)` 可切换，数据、几何、事件都一样（对比图 [`color-directions.jpg`](color-directions.jpg)，Apple 式的详图 [`crystal-aurora.jpg`](crystal-aurora.jpg)）：

- **珍珠母 `lit`**（上一版推荐）：平时是安静的珍珠母，极光只在事情发生时沿轮廓出现。极光强度：封存 0.7 × p本体 / 0.8 × p影子，待揭晓 0.12–0.14，结果 0.5 + 0.9 × 意外，继承 1.1，每秒衰减约 0.9。
- **The Expanse 式 `expanse`**：一束硬光、陶瓷与金属、琥珀与青色的仪表光。仪表语言（细线、刻度、读数）适合剖面、细纹读数和接口透视，不适合晶体的皮肤。

### 11.6 质感：极光水晶

形状从圆球改成晶体，轮廓照那颗绿色的宝石（修长，上尖短、下尖长）。只有一层：五彩极光就在晶体的表面上，几个打磨光滑的面，棱不画线。晶莹来自光：刻面的明暗、扫过刻面的直边反光、映在面上的天光（详图 [`crystal-aurora.jpg`](crystal-aurora.jpg)）。

走过的路（每一条都是一轮反馈）：

1. **釉面月光石**（圆球）：颜色在一层磨砂下面，里面浮着一片柔光。柔和，但“塑料感”，也不像晶体。
2. **光线追踪的宝石**：光在晶体里真的多次全反射、带色散的火彩，摄影棚里围着灯带与黑旗。更像钻石，但碎成很多块（“设计太差”）。
3. **看得见背面的玻璃**：背面的棱、按背面分块的折射错位都画出来。面上多了很多折痕（“没有那么多褶皱，就是几个面”）。
4. **平涂的刻面**：每个面一段干净的渐变。干净，但像一张矢量图（“显然不行”）。
5. **清玻璃里一颗发光的心**：有深度，但成了两层（“不应该设计成 2 层，外表层是极光五彩，只有一层，晶体晶莹”）。
6. **一层，描白线**：极光在表面上，每条棱一道白线，像线框（“每个边都有白色的一根线，可以去掉，再打磨下表面”）；颜色是一团团的喷绘，高光是鼓起来的弧形。
7. **一层，光把面分出来**（这一版）：棱不画线；每个面一段简洁的线性渐变；平面上的直边反光。

全部在一个着色器里（`materials.js · dbbGlass`），只用到这个面自己的法线和位置，不需要额外的渲染通道：

| 层 | 做法 | 参数（`LOOKS.apple.glass`） |
|---|---|---|
| 极光 | 见 11.2：每个面以中间一段方位为主，纵向往尖的颜色渐变；色相随角度偏 `(1 − n·v) × 0.8` 弧度（全息），每个面偏得不一样，棱两边的颜色分得开 | `iri 0.8` |
| 刻面 | 明暗 `s = 0.62 + 0.55·(0.7·K主光 + 0.3·K头顶)`，K = `n·l × 0.5 + 0.5`；在感知亮度上做（`L × s^⅓`，彩度留着）：暗的面是浓郁的宝石色，不发灰；黄色在暗处往琥珀橙偏（暗处更暖），不发橄榄。朝光的面朝同一个色相提亮（`L + 0.12`）。棱不画线：两个面的明暗与颜色不一样，棱自己就出来了 | `facet [0.62, 0.55]` · `lit 0.35` |
| 光 | 主光在整颗晶体上的一片光：× `(0.9 + 0.14·smoothstep(−0.45, 0.95, p̂·l))`，跨过棱是连续的 | 同上 |
| 高光 | 平的面反射柔光箱（圆角矩形，里面上亮下暗），边界是直的；只为算反光把镜头拉近到三分之一，反光方向在面上变化大一些，转动时一条直的明暗边界扫过刻面。面上再映出头顶的一段天光（`smoothstep(0.3, 0.95, r_y)`）。掠射处按 `F = 0.04 + 0.96·(1 − cosθ)^5` 反射摄影棚 | `gloss 1` · `glaze 1` |

- 倒影：世界坐标的 y 在着色器里翻回来（`uMirrorY = −1`），倒影就是同一个东西在水里的样子。
- 剖开：上面的尖顶抬起、向后翻开。剖面是一圈套一圈的菱形环带，每一圈靠外的边缘更亮，表面一层柔和的光泽，同样跟着指针；不做色调映射，和晶体对得上。
- 醒过来：第一次出现时，浓度从 0（诞生般的淡）以每秒 1.1 的速度升到它该有的值。
- 呼吸：亮度 ±4%；事情发生时按浓度亮一点；很久没人理它，暗一点。
- 光跟着注意力：鼠标悬停、按住的手指、手机倾斜（只在不需要授权的设备上监听 `deviceorientation`，基准慢慢跟上握持角度，只对“变化”有反应）。
- 减少动态效果：流动、呼吸、倾斜关闭；浓度直接到位。
- 物理材质只留最基本的一层（不算虹彩、清漆、绒光），省下手机上的算力。

## 12. 已知限制

- 需要 WebGL2（顶点着色器里用 `inverse()` 把镜头与主光换到局部坐标）。颜色场最多认 8 类事。低端手机上帧率会下降；像素比已限制在 1.75–2，倒影渲染在半分辨率。
- 声音只写了建议，没有实现；触觉只在支持 `navigator.vibrate` 的设备上有效（iOS Safari 不支持）。
- three r186 的 `morphcolor_vertex` 有一个类型错误，`materials.js` 里替换成了修正版（`MORPHCOLOR_FIX`）；升级 three 后可以去掉。
- 演示数据的细纹由固定种子生成；真实数据需要账本里的 `lamellae`。
